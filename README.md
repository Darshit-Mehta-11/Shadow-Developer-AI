# 🚀 Shadow Developer AI

Turn any GitHub profile into actionable engineering insights.

Shadow Developer AI is an AI-powered GitHub Intelligence Platform that analyzes repositories, technologies, coding patterns, project maturity, and developer growth signals to generate personalized engineering insights, career roadmaps, and recruiter-focused intelligence.

---

## ✨ Features

### 🧠 Shadow AI Analysis
- Repository-level intelligence
- Engineering direction detection
- Technology focus analysis
- Learning behavior insights
- Portfolio maturity evaluation
- Technical growth opportunities

### 🚀 AI Career Roadmap
- Personalized skill recommendations
- Technology growth paths
- Project-building suggestions
- Career progression guidance
- Next-step learning recommendations

### 🎯 Recruiter Intelligence
- Hiring signal evaluation
- Internship readiness assessment
- Engineering potential analysis
- Recruiter-focused profile insights
- Portfolio strength evaluation

### 📊 GitHub Analytics
- Repository analysis
- Language distribution
- Stars and forks tracking
- Contribution patterns
- Developer activity overview

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### APIs
- GitHub REST API
- Google Gemini AI

---

## 📷 How It Works

1. Enter a GitHub username or profile URL.
2. Shadow AI fetches GitHub profile data.
3. Repositories are analyzed.
4. AI generates:
   - Engineering Insights
   - Career Roadmap
   - Recruiter Intelligence
5. Results are displayed in a clean dashboard.

## ⚡ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Shadow-Developer-AI.git
cd Shadow-Developer-AI
```

### Backend Setup

```bash
cd server
npm install
```

Create `.env`

```env
PORT=5000
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Run backend:

```bash
npm run dev
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```
